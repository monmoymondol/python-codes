# 🐍 Python Codes

Welcome to **monmoymondol/python-codes** — a collection of Python projects ranging from simple beginner scripts to advanced applications.  
This repository is designed to help learners and developers explore Python through practical examples, creative tools, and real-world mini‑projects.

---

## 📘 About

This repository contains various Python programs that demonstrate:
- Core programming concepts (loops, functions, data structures)
- GUI development using **Tkinter** and **CustomTkinter**
- File handling and data persistence (JSON, SQLite)
- Object‑oriented programming (OOP)
- Algorithmic problem solving
- Game development and interactive tools

Each project is self‑contained and easy to run — perfect for learning, experimenting, or building upon.
