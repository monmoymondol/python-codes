# 🎥 YouTube Downloader GUI

A simple GUI YouTube downloader built with Python, Tkinter, and Pytube.  
Supports **video download**, **audio-only download**, and **resolution selection**.

## 📂 Project Structure (GUI version)


youtube_downloader_gui/                                                                                                                        
├── src/                                                                                                                                       
│   ├── youtube_downloader_gui.py     # GUI app                                                                                                  
│   └── downloader.py                 # core download logic                                                                                      
├── requirements.txt                                                                                                                            
├── README.md                                                                                                                                   
└── downloads/                        # default folder for saved files                                                                            

---

## 🚀 Features
- Paste YouTube link in a text box.
- Choose output folder with a file dialog.
- Select audio-only or specific resolution.
- Click **Download** and get progress messages.
